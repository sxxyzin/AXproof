# AX Proof 플랫폼 v1.2 (2026.11.08)

AI 시대에 스스로 판단하는 사람을 키우는 교육 플랫폼입니다. 대학생·취준생 실무 훈련을 중심으로 **대화 판단의 비공개 포트폴리오 자동 수집**, **공유시간**, **초중고 생각 훈련·교사 관찰·보호자 리포트**를 추가했습니다.

현재 구현과 연결 순서는 **[06 플랫폼 확장과 실서비스 전환](docs/06_플랫폼확장과실서비스전환_v1.2.md)**을 먼저 읽으세요. 이전 기획 문서의 v1.1 기준 설명은 이 문서로 보완합니다. 실제 AI 키·Supabase·Vercel 연결 시험은 별도이며 아직 배포하지 않았습니다.

링커스의 링커슈 → 개인 프로젝트 → 팀 프로젝트 흐름과 Decision Log를 하나의 웹 서비스로 만든 결과물입니다.

| 폴더·파일 | 내용 |
|---|---|
| `docs/AXProof_기획안_v2.html` | **기획안 HTML** — 아래 문서 5종 + 화면 30장을 파일 하나로 (더블클릭으로 열림) |
| `docs/01_AXProof_서비스기획서_v2.md` | Why · What · How 기획서 |
| `docs/02_사용자시나리오_v3.md` | 훈련생 우서진(HRD) · 현직 멘토 · 운영진 · 공공기관 · 기업 HR |
| `docs/03_화면설계_기능명세.md` | IA, 화면별 기능, 데이터 모델, API, 운영 정책 |
| `docs/04_멘토피드백_반영표.md` | 피드백·결정사항 반영 + 남은 확인 질문 |

## 바로 실행
1. `web/start.bat` 더블클릭 (Node.js 필요) → 브라우저가 열리면 "훈련생으로 둘러보기"
2. 또는 `web/public/app.html`을 더블클릭하면 서버 없이 데모 모드로 열립니다.
